# Documentation archive

Files in this directory are completed delivery records or dated evidence. They
explain how the current system was reached, but they are **not** current
roadmaps, architecture authorities or production claims.

Use:

- `../status/current.md` for current implementation/release state;
- `../v2-product-architecture.md` for the current product/domain model;
- `../architecture.md` and `../frontend-architecture.md` for durable technical boundaries;
- `../capacity-plan.md` for current capacity proof requirements.

Archived records:

- `v2-delivery-plan-2026-09.md` — completed V2.1-V2.8 repository execution plan;
- `live-load-results-2026-08.md` — dated local pre-v2 live-load evidence;
- `frontend-f0-f5-2026-08.md` — F0-F5 frontend modernization history;
- `frontend-f5-quality-baseline-2026-08.md` — dated F5 bundle/browser baseline;
- `legacy-to-go-migration-parity.md` — completed Django/Rust-to-Go parity record.

Historical evidence may inform a new decision, but current claims require fresh
verification on the topology/version named by the relevant current document.
